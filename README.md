# 🌿 FloraPulse — Plant Care Website

A responsive plant care website that helps plant lovers explore houseplants, understand their care needs, and estimate watering schedules. Built with HTML, CSS, and JavaScript, with a dark botanical theme and subtle visual effects.

## ✨ Features

- **Plant directory:** Explore 16 curated plant profiles with photos and care information.
- **Search and filters:** Find plants by name, light requirements, watering needs, maintenance level, and pet safety.
- **Detailed care profiles:** Learn about soil, fertilizer, humidity, propagation, pruning, and common problems.
- **Watering calculator:** Estimate a care schedule based on species, pot size, season, light, and room climate.
- **Saved favorites:** Keep your favorite plants easy to find.
- **Care guides and FAQs:** Discover practical tips for healthier houseplants.
- **Contact and newsletter forms:** Frontend interfaces for plant care inquiries and subscriptions.
- **Responsive dark theme:** Deep forest backgrounds, mint accents, floating light particles, and glowing hover effects.
- **Reduced-motion support:** Animations respect the visitor’s motion preferences.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts — Plus Jakarta Sans and Playfair Display

## 📁 Project Structure

```text
plant-care-website/
├── index.html       # Page structure and content
├── styles.css       # Theme, responsive layout, and effects
├── app.js           # Plant data and interactive features
└── assets/          # Plant photographs
```

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

You can also run the project through a local development server, such as VS Code’s Live Server extension.

## 🌐 Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select your branch and the **root** folder, then save.

Keep `index.html`, `styles.css`, `app.js`, and `assets/` together so links and images load correctly.

## 📝 Notes

- Watering estimates are starting points. Check soil moisture and your plant’s condition before watering.
- Contact and newsletter forms require a backend or form service to deliver messages and store subscriptions.

## 🤝 Contributing

Suggestions, bug reports, and improvements are welcome. Open an issue or submit a pull request.
